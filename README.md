# React em Prática — Guia Interativo

Aplicação web interativa desenvolvida com React e Vite, com CSS puro simples. O projeto apresenta 8 conteúdos didáticos sobre desenvolvimento web, com funcionalidade de marcar conteúdos como revisados e um painel de dúvidas.

## Tecnologias utilizadas

- React (biblioteca de interface)
- Vite (build tool e servidor de desenvolvimento)
- CSS puro
- HTML5

## Comandos para rodar localmente

```bash
npm install
npm run dev
```

O aplicativo estará disponível em `http://localhost:5173`.

## Build

```bash
npm run build
```

## Nota sobre versionamento

Este projeto foi desenvolvido utilizando uma branch `desenvolvimento`, que foi integrada à branch `main` ao finalização das atividades.
